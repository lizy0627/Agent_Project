# Codex White Bear Desktop Pet Asset Pack

A 20-state desktop pet asset pack for a coding AI assistant named Codex, generated from the uploaded white bear image as the only character reference.

## Contents

- `codex-bear-20-state-sheet-1400x1120.png` - transparent 5x4 master sheet
- `codex-bear-20-state-sheet-chroma.png` - original chroma-key source sheet
- `states/*.png` - transparent per-state PNG exports, 280x280 each
- `manifest.json` - state ordering, filenames, grid positions, and alpha bounding boxes
